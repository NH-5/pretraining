# Ex2 分层提示：把代码讲明白

本题不是背术语，而是把 Ex1 的运行路径压缩成三张“口述卡”。先读指南
§3.1、§6.1、§6.3，然后运行：

```bash
uv run python exercises/ex02_nanogpt_walkthrough/train.py trace
uv run python exercises/ex02_nanogpt_walkthrough/train.py check
```

`answers.py` 中每项写 3–5 句即可。建议每张卡都包含：

1. 一句不变量；
2. 一个 4-token 小例子；
3. 关键 shape 或控制流；
4. 违反不变量会发生什么。

### 提示 1

不要只说“用了下三角矩阵”。先说语义：位置 `t` 的表示里能包含哪些输入信息。

### 提示 2

补上因果链：若位置 `t` 读到了未来 token，模型在训练时会获得本应预测的答案，
loss 可能很好看，但生成时没有这份未来信息。

## EX02_EXPLAIN_TOKEN_LOSS

### 先画对齐

```text
序列  : A  B  C  D
输入  : __ __ __
目标  : __ __ __
```

再填：

```text
模型输出 logits: [B, T, ____]
目标 targets    : [B, T]
一次 forward 提供 ____ 次 V 类分类（按每个 batch 计）
```

### 提示 1

普通句子分类通常一条样本只有一个标签；这里每个可预测位置都有一个标签。说明
“逐 token”时要把这个差别说出来。

### 提示 2

把公式翻成代码路径：原序列右移得到 targets；模型并行输出所有位置；计算每个
位置的交叉熵；最后对有效 token 聚合。见指南 §6.1、§6.3。

### 自检

回答：“若只对最后一个 token 算 loss，会浪费掉哪部分训练信号？”

### 提示 1

训练数据已经给出整条序列，所以不同位置的 targets 同时存在；生成时下一个输入

### 提示 2

口述时把“序列位置可并行”和“网络层仍按层执行”区分开。本题问的是时间位置之间
为什么训练可并行、推理有自回归依赖，不是说整张计算图没有顺序。

## check 的含义

- `PENDING`：对应字符串仍为空；
- `MANUAL`：已检测到非空答案，接下来必须脱稿口述；
- `PASS training trace wiring`：脚本的右移对齐正确，不代表你的解释已经清楚；
- `verify` 只做长度等结构检查，不能用关键词替代语义判断。

最后请真的关掉 `answers.py`，用 `trace` 的一个位置举例讲给自己听。
